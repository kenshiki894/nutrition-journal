NUTRITION JOURNAL — STANDALONE WEB APP

Files: index.html, app.js, manifest.webmanifest, icon.svg, sw.js

To run locally: unzip the folder, then in the folder run:
  python -m http.server 8000
Open http://localhost:8000 in a browser.

To install on Android:
1. Upload all files (not the ZIP itself) to a static hosting service with HTTPS (such as Netlify Drop, GitHub Pages or Cloudflare Pages).
2. Open the resulting HTTPS URL in Chrome on Android.
3. Choose the browser menu > Add to Home screen / Install app.

The app is independent of ChatGPT. Food nutrition is a limited starter library of estimates. Meal parsing is rule-based, not AI. All entries are stored locally in the browser. Use Settings > Export backup to protect your data.
